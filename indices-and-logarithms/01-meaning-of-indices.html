INDICES & LOGARITHMS · LESSON 01

Meaning of Indices

Understand base, index and repeated multiplication.

⏱️ 25–40 min 📘 Foundation

🎯 Learning Objectives

  • identify the base and index;
  • write repeated multiplication in index form;
  • evaluate simple powers, including index zero.

What does an index mean?

An index tells us how many times the base is used as a factor.

a n = a × a × ··· × a   (n factors)

Base

In 3 4 , the base is 3.

Index

The index is 4, so 3 is multiplied by itself four times.

Value

3 4 =3×3×3×3=81 .

✏️ Worked Example

Write 5×5×5×5×5 in index form.

The repeated factor is 5, so the base is 5.
There are five factors, so the index is 5.
Answer: 5 5 .
