GRAPHS · LESSON 07

Gradient and Intercepts

Understand steepness, rate of change and where a line meets the axes.

⏱️ 15–18 min 📘 Developing ✏️ Worked examples included

🎯 By the End of This Lesson...

  • calculate the gradient of a straight line;
  • interpret gradient as a rate of change;
  • identify x- and y-intercepts;
  • connect a line to y = mx + c;
  • write the equation of a simple straight line.

🤔 Think About This...

Two roads rise by the same height, but one covers a much shorter horizontal distance.

Which road is steeper, and how could mathematics measure that steepness?

The gradient compares vertical change with horizontal change.

📐

See Gradient as Rise ÷ Run

Change the rise and run. The line and gradient update together.

What Is Gradient?

gradient = change in y ÷ change in x
Key idea: Gradient tells us how much y changes whenever x changes by one unit.

Positive gradient

The line rises from left to right.

Negative gradient

The line falls from left to right.

Zero gradient

The line is horizontal.

Larger magnitude

The line is steeper.

Worked Example: Finding Gradient

Find the gradient through A(1, 3) and B(5, 11).

1

Change in y = 11 − 3 = 8.

2

Change in x = 5 − 1 = 4.

3

Gradient = 8 ÷ 4 = 2.

4

For every 1 unit increase in x, y increases by 2.

Intercepts

An intercept is where a graph crosses an axis.

  • The y-intercept occurs where x = 0.
  • The x-intercept occurs where y = 0.
y = mx + c

In this form, m is the gradient and c is the y-intercept.

Worked Example: Reading an Equation

For y = 3x − 4:

1

m = 3, so the gradient is 3.

2

c = −4, so the graph crosses the y-axis at (0, −4).

3

To find the x-intercept, set y = 0: 0 = 3x − 4, so x = 4/3.

Finding the Equation of a Line

Suppose a line has gradient 2 and y-intercept 5.

y = 2x + 5
Common mistake: Using a point as the gradient. Gradient is a ratio of two changes, not a coordinate.

✅ Quick Check

State the gradient of y = 5x + 2.
State the y-intercept of y = −2x + 7.
Find the gradient through (2, 1) and (6, 9).

Practice Questions

Foundation
  1. State m and c for y = 4x − 3.
  2. Find the gradient through (0, 2) and (3, 8).
  3. Write the equation of a line with gradient 5 and y-intercept −1.
Developing
  1. Find the x-intercept of y = 2x − 10.
  2. A line passes through (0, 4) and (5, 14). Find its equation.
  3. Explain the meaning of a negative gradient in a real-life graph.
Challenge
  1. A line passes through (2, 7) and has gradient 3. Find its equation.

One-Minute Summary

  • Gradient is change in y divided by change in x.
  • The y-intercept occurs where x = 0.
  • The x-intercept occurs where y = 0.
  • In y = mx + c, m is gradient and c is y-intercept.
