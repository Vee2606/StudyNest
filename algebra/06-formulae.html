🤔 Think About This...

Suppose one cinema ticket costs $8. If two friends go, they pay:

2 × 8 = 16

If five friends go, they pay:

5 × 8 = 40

Instead of writing a new calculation every time, we can write one rule that always works.

C = 8n

where C is the total cost and n is the number of people.

That rule is called a formula.

📖 What is a Formula?

A formula is a mathematical rule that shows the relationship between different quantities.

Instead of solving the same problem repeatedly, we write one formula that can be used over and over again.

Think of a formula as a recipe. If you follow the recipe correctly, you will always get the correct answer.

🌍 Formulae Around Us

🚕 Taxi Fare

Cost = Fare × Trips

🍞 Bread

Cost = Price × Loaves

⚽ Football

Total = Ticket Price × Number of Tickets

📱 Mobile Data

Cost = Price × Bundles

📝 Worked Examples

Example 1

The formula for the perimeter of a square is

P = 4s

Find the perimeter when s = 6 cm.

Thinking...

P = 4 × 6
P = 24 cm

Example 2

The total cost of apples is

C = 3a

Find C when a = 5

C = 3 × 5
C = 15

Example 3

Area of a rectangle:

A = l × w

Find A when l = 8 and w = 5

A = 8 × 5
A = 40

⭐ The StudyNest Shortcut

Read → Replace → Calculate
  1. Read the formula carefully.
  2. Replace every letter with its value.
  3. Calculate the answer.

⚠ Common Mistakes

Students often replace the wrong letter. Always check which value belongs to which variable before calculating.
