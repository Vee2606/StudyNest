TRANSFORMATIONS · LESSON 08

Transformation Matrices

Calculate images and identify transformations represented by matrices.

⏱️ 26–38 min 📘 Challenge 📍 Coordinate diagrams included
T ↻ k=2

🎯 Learning Objectives

  • use 2×2 matrices to transform coordinates;
  • recognise standard reflection, rotation and enlargement matrices;
  • determine a matrix from basis-vector images;
  • interpret a transformation matrix.

Matrix Mapping

If A is a transformation matrix, then image vector = A × object vector.

The first column is the image of (1,0); the second column is the image of (0,1).

Worked Example

Apply 0−110 to (3,2).

x′=0(3)−1(2)=−2.

y′=1(3)+0(2)=3.

Image=(−2,3), a 90° anticlockwise rotation.

Practice

  1. Apply 100−1 to (4,−3).
  2. Apply 2002 to (−1,5).
  3. Identify 0110.

🧠 Learn It Visually: Transformation Matrices

A 2×2 matrix can act like a movement rule. Multiplying the matrix by a point’s column vector produces the image coordinates.

Point as a column vector

Represent (x,y) as a vertical vector with x above y.

Multiply carefully

Use row-by-column multiplication to find x′ and y′.

Recognise common matrices

Different matrices represent reflections, rotations, stretches, enlargements and shears.

Think Like a Mathematician: Why must every vertex be multiplied by the same transformation matrix?

🧷 Remember

The matrix acts on position vectors measured from the origin, so these transformations are centred on or fixed relative to the origin.

⚠️ Common Mistake

Multiplying coordinates in the wrong order or treating the point as a row vector.

🎯 Exam Tip

Calculate one vertex, check the expected movement, then transform the remaining vertices.

🧭 StudyNest: How to Solve Transformation Problems

1 Compare Look at the object and image before calculating anything.
2 Identify Decide whether the change is a slide, flip, turn, resize, stretch or shear.
3 Locate Find the vector, mirror line, centre, invariant line or centre of enlargement.
4 Measure Determine direction, angle and scale factor where needed.
5 Map Apply the coordinate rule or matrix to one vertex at a time.
6 Plot Plot every image point accurately and join them in the same order.
7 Describe Name the transformation completely—not only its type.
8 Check Verify distances, orientation, size and invariant features.
