TRANSFORMATIONS · LESSON 02

Translations

Slide every point by the same horizontal and vertical movement.

⏱️ 26–38 min 📘 Foundation 📍 Coordinate diagrams included
T ↻ k=2

🎯 Learning Objectives

  • translate points and figures using column vectors;
  • find the translation vector from an object and image;
  • describe translations completely;
  • reverse a translation.

Translation Vector

The vector (a,b) moves every point a units horizontally and b units vertically.

Horizontal

Positive means right; negative means left.

Vertical

Positive means up; negative means down.

Worked Example

A(1,2) maps to A′(5,−1).

Horizontal movement: 5−1=4.

Vertical movement: −1−2=−3.

Translation vector=(4,−3).

Coordinate Rule

(x,y) → (x+a,y+b).

Practice

  1. Translate P(2,−1) by (4,3).
  2. Find the vector taking A(−2,5) to A′(3,1).
  3. What vector reverses translation (6,−2)?

✅ Check Your Work

Show answers and working
  1. P′=(2+4,−1+3)=(6,2).
  2. (3−(−2),1−5)=(5,−4).
  3. (−6,2).

🧠 Learn It Visually: Translations

A translation is a slide. Every point moves the same distance in the same direction, so the image keeps the same size, shape and orientation.

Column vector

Write the movement vertically: top number = horizontal, bottom number = vertical.

Signs matter

Positive horizontal means right; negative means left. Positive vertical means up; negative means down.

Finding the vector

Subtract object coordinates from image coordinates: image − object.

🎛️ Translation Animator

Choose a horizontal and vertical movement. The same movement is applied to every vertex.

A positive horizontal value moves right; a positive vertical value moves up.
Think Like a Mathematician: Why is it enough to calculate the movement of just one correctly matched vertex?

🧷 Remember

A translation has no centre and no mirror line. It is fully described by its vector.

⚠️ Common Mistake

Writing the vector in the wrong order. Horizontal movement must be written above vertical movement.

🎯 Exam Tip

State “translation by the vector …”, including signs. Do not write only “translation”.

🧭 StudyNest: How to Solve Transformation Problems

1 Compare Look at the object and image before calculating anything.
2 Identify Decide whether the change is a slide, flip, turn, resize, stretch or shear.
3 Locate Find the vector, mirror line, centre, invariant line or centre of enlargement.
4 Measure Determine direction, angle and scale factor where needed.
5 Map Apply the coordinate rule or matrix to one vertex at a time.
6 Plot Plot every image point accurately and join them in the same order.
7 Describe Name the transformation completely—not only its type.
8 Check Verify distances, orientation, size and invariant features.
