SETS · LESSON 01

Introduction to Sets

Discover how mathematics organises clear collections of objects.

⏱️ 15–18 min 📘 Foundation ✏️ Worked examples included
A B A ∩ B
A ∪ B A′

🎯 By the End of This Lesson...

You should be able to:

  • explain what a set is in plain English;
  • distinguish well-defined collections from vague collections;
  • identify elements of a set;
  • use braces correctly;
  • use the symbols ∈, ∉ and n(A).

🌍 Why This Matters

Sets give us a precise way to organise objects and information. The language you learn here will return in probability, statistics, functions and data handling.

🌍 Where Will You See Sets?

Sets are used in surveys, databases, probability, statistics, computer programming and search systems. Whenever information is sorted into clear groups, set ideas are nearby.

🤔 Think About This...

Imagine asking every learner in a class who plays football to stand on one side of the room.

The learners standing together form a collection. Can we decide clearly whether each learner belongs to that collection?

Yes. A learner either plays football or does not. Mathematics calls a clear collection like this a set.

What Is a Set?

A set is a well-defined collection of objects. The objects inside a set are called elements or members.

Key idea: A collection is well-defined when we can decide clearly whether an object belongs to it.

A = {2, 4, 6, 8}

See a set as a clearly defined collection

A set must be well defined: we should be able to decide whether an item belongs.

Well-Defined or Not?

Well-defined

“The months with 31 days.” Every month can be checked.

Not well-defined

“The beautiful months.” Beauty depends on personal opinion.

Well-defined

“Prime numbers less than 20.” Membership follows a clear rule.

Not well-defined

“Very large numbers.” The meaning of “very large” is unclear.

Important Set Symbols

∈ is an element of
∉ is not an element of
n(A) number of elements in A

Let A = {2, 4, 6, 8}.

1

4 ∈ A because 4 appears in the set.

2

5 ∉ A because 5 does not appear in the set.

3

n(A) = 4 because A has four elements.

Does Order Matter?

In a set, the order of the elements does not matter.

{1, 2, 3} = {3, 1, 2}

Repeating an element also does not create a new element.

{1, 1, 2, 3, 3} = {1, 2, 3}

🌟 Did You Know?

The modern language of sets became one of the foundations of mathematics because it gives mathematicians a precise way to describe collections and relationships.

🔍 How Do I Recognise a Sets Question?

Look for:

  • groups or collections;
  • membership symbols such as ∈ or ∉;
  • braces { };
  • questions asking how many elements are in a group;
  • instructions to list or describe a collection.

⚠️ Common Mistakes

Mistake 1: Counting repeated elements more than once.

Mistake 2: Using brackets ( ) instead of braces { }.

Mistake 3: Calling a vague collection a set.

✅ Quick Check

Is “the best footballers” well-defined?
If B = {a, e, i, o, u}, is e ∈ B?
Find n({2, 4, 4, 6}).

💡 Exam Tip

When listing a set, use braces and write each distinct element only once. The order of elements does not affect the set.

Practice Questions

  4. Find n(A).
Confidence
  1. Write the set of vowels in the word MATHEMATICS. Do not repeat elements.
  2. Explain why {1, 2, 3} and {3, 2, 1} describe the same set.
Challenge
  1. A collection is described as “the small natural numbers.” Explain why this is not well-defined and rewrite it as a set.

One-Minute Summary

  • A set is a well-defined collection.
  • Objects inside a set are elements.
  • Use braces { } to write sets.
  • ∈ means belongs; ∉ means does not belong.
  • n(A) gives the number of distinct elements in A.
